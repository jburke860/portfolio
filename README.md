# Jeremy Burke Portfolio

Personal portfolio website for software engineering, applied AI, and technical R&D roles.

Live site: [https://jeremyburke.vercel.app](https://jeremyburke.vercel.app)

## Overview

This portfolio highlights my background in applied AI, computer vision, sensor fusion, simulation, automation, and technical software development. Some professional work is summarized at a high level due to contractual and confidentiality constraints, while public demo projects are being developed separately to show implementation style and code quality.

## Tech Stack

- Next.js
- TypeScript
- Tailwind CSS
- Vercel

## Sections

- Selected technical work summaries
- Public demo projects
- Skills and tools
- About
- Contact links

## Local Development

To run the site locally:

```bash
npm install
npm run dev
```
